# pericircle

<!-- badges: start -->

<!-- badges: end -->

The `pericircle` package acts like `tidyverse` for packages used and developed
by [Perisphere RWE](https://www.perisphere-rwe.com/). The code in `pericircle`
is a slightly modified version of the
[tidyverse](https://github.com/tidyverse/tidyverse) code, which is provided
under the terms of the MIT license (see LICENSE file).

## Installation

You can install the development version of `pericircle` with

``` r
# install.packages("pak")
pak::pak("perisphere-rwe/pericircle")
```

Then, `library(pericircle)` will attach the following packages:

- [pericircumference](https://github.com/perisphere-rwe/pericircumference)
- [perinary](https://github.com/perisphere-rwe/perinary)
